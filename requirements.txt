# Бот-уведомитель для Telegram

Присылает тебе в чат с ботом карточку на каждое сообщение от выбранных людей:

```
📩 Новое сообщение

👤 Кто писал: Иван Петров (@ivan)
📅 Дата: 11 ноября 2026, среда
🕒 Время: 03:43
💬 Что писал:
│ встретимся в 5
✏️ Изменено на (03:50):
│ встретимся в 5, у метро     ← дописанное выделено жирным
```

Меню бота (`/menu`): **🎯 Цели** (напоминания), **👥 Люди** (от кого принимать сообщения), **📝 Заметки**.

## Как это устроено

Один процесс, два Telegram-клиента:

- **твой аккаунт** (юзербот) только *читает* входящие личные сообщения. Он ничего не отправляет и не помечает сообщения прочитанными;
- **бот из @BotFather** присылает уведомления и показывает меню. Отвечает только владельцу аккаунта, остальным молчит.

Обычный бот не может читать твою личную переписку, поэтому нужен вход в аккаунт.

## Что понадобится

1. `api_id` и `api_hash`: https://my.telegram.org → API development tools.
2. Токен бота: @BotFather → `/newbot`.
3. Linux-сервер (VPS) с Python 3.9+ и доступом по SSH.

## Установка на сервер

```bash
# с компьютера: загрузить на сервер
scp tgnotify.zip user@SERVER:~/
ssh user@SERVER
unzip tgnotify.zip && cd tgnotify

# дальше запускай один и тот же скрипт: после каждого шага он подскажет, что делать
bash deploy/install.sh        # поставит зависимости и создаст .env
nano .env                     # впиши TG_API_ID, TG_API_HASH, BOT_TOKEN
bash deploy/install.sh        # проверит .env
./venv/bin/python login.py    # телефон, код из Telegram, пароль 2FA (если есть)
bash deploy/install.sh        # включит автозапуск (systemd)
```

После этого бот работает как служба: переживает перезагрузку сервера и перезапускается при сбоях.

Если `login.py` удобнее запустить на своём компьютере, скопируй потом на сервер всю папку `data/` целиком (в ней сессия и метка успешного входа).

**Последний шаг:** открой своего бота в Telegram, нажми `/start` (без этого он не может тебе писать), затем **Люди → Добавить человека**.

Если нужен только запуск «вручную» (для проверки): `./venv/bin/python bot.py`.

## Как пользоваться

**Люди.** Добавить можно по `@username`, номеру телефона (если он в контактах), ID, пересланному от человека сообщению или кнопкой «Из недавних чатов». Переключатель режима: «только от выбранных» (по умолчанию) или «от всех».

**Цели.** Нажми «Новая цель», напиши дату (и время, если нужно), потом что напомнить. Или всё сразу в одной строке:

| Что написать | Когда сработает |
|---|---|
| `25.12 18:30` | 25 декабря в 18:30 |
| `завтра в 9:00`, `послезавтра 18.30` | как написано |
| `через 2 часа`, `через полчаса`, `через 3 дня` | считается от текущего момента |
| `15.01.2027` | в 09:00 (время по умолчанию, меняется в `.env`) |
| `25.12 18:30 купить подарок` | сразу создаёт цель с текстом |

В назначенное время бот присылает «⏰ Время пришло!». Если сервер в этот момент был выключен, напоминание придёт сразу после запуска с пометкой о задержке.

**Правки.** Если человек отредактировал сообщение, к исходной карточке добавляется блок «✏️ Изменено на». Правок может быть несколько, исходный текст остаётся. Если правка не помещается в лимит Telegram (4096 символов), она приходит отдельным сообщением-ответом.

## Что важно знать

- Работает только с **личными чатами** (группы и каналы не отслеживаются). Вложения показываются описанием («🖼 Фото», «📎 Файл: …») плюс подпись, сам файл не пересылается. Удаление сообщений не отслеживается.
- Если бот был выключен, после запуска он подтянет пропущенные сообщения (на практике это работает, пока выключен недолго: от часов до пары дней).
- В режиме «от всех» не пересылаются другие боты и служебные сообщения Telegram (там приходят коды входа).
- **Безопасность:** папка `data/` содержит сессию, это полный доступ к твоему аккаунту. Никому не отдавай, не заливай в git (`.gitignore` уже это учитывает). Отозвать доступ можно в Telegram: Настройки → Устройства → «Message Notifier» → Завершить сеанс.
- Архив с историей уведомлений хранится 30 дней (нужен только для отслеживания правок).

## Управление

```bash
journalctl -u tgnotify -f          # логи
sudo systemctl restart tgnotify    # перезапуск
sudo systemctl stop tgnotify       # остановить
```

Обновление кода: заменить `.py`-файлы (папку `data/` и `.env` не трогать) и перезапустить службу.

## Проверка кода

```bash
./venv/bin/python -m unittest discover -s tests -v
```

Тесты не требуют Telegram: проверяют разбор дат, формат карточек, правки, напоминания и меню на подставных объектах.
